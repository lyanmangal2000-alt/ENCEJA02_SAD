Seção 1
O que você vai rodar
O projeto entrega um Sistema de Apoio à Decisão (SAD) que prevê o desempenho de novos candidatos do ENCCEJA com o algoritmo K-Nearest Neighbors e converte a previsão em recomendações gerenciais para cursinhos preparatórios. Ele é composto por duas interfaces independentes que compartilham a mesma base de dados e a mesma lógica de modelagem. Não é necessário rodar as duas para avaliar o trabalho: cada uma cobre o ciclo completo de previsão e recomendação.
● Interface 1 — App Streamlit (Python)
Carrega o modelo K-NN treinado pelo pipeline (modelo_knn.joblib) e oferece três abas: Simulador de Matrícula, Base Histórica e Modelo & Métricas. Roda em http://localhost:8501.
● Interface 2 — Dashboard Next.js (Web)
Replica o K-NN inteiramente no navegador em TypeScript, com cinco módulos: Visão Geral, Simulador K-NN (com presets de demonstração), Recomendação, Análise Exploratória e Modelo & Métricas. Roda em http://localhost:3000.
O fluxo de dados é simples de entender: o pipeline Python lê os microdados (sintéticos ou oficiais do INEP), aplica o ETL, normaliza as variáveis com Z-score, treina o K-NN e serializa o modelo; o Streamlit consome esse modelo treinado; já o dashboard Next.js recebe uma amostra exportada da base com os parâmetros de padronização e executa a mesma aritmética de vizinhos no cliente. Por isso, o Streamlit depende da etapa de treinamento, enquanto o dashboard web funciona imediatamente após o npm install.

Seção 3
Interface 1 — App Streamlit (Python)
Esta é a interface principal do trabalho acadêmico: ela executa o modelo K-NN treinado pelo pipeline e gera o parecer gerencial automaticamente. Todo o processo acontece no terminal integrado do VSCode, que você abre com o atalho Ctrl + ` (ou menu Terminal → New Terminal). Os comandos abaixo devem ser executados dentro da pasta projeto_knn_encceja, aberta no VSCode por File → Open Folder.
1
Criar o ambiente virtual
O ambiente virtual isola as bibliotecas do projeto das do sistema, evitando conflitos de versão. Execute uma única vez:
> python -m venv .venv
2
Ativar o ambiente virtual
O comando varia conforme o sistema operacional. Após ativar, o terminal passa a exibir (.venv) no início da linha:
Windows — PowerShell
> .venv\Scripts\Activate.ps1
Windows — Prompt de comando (cmd)
> .venv\Scripts\activate.bat
Linux / macOS
$ source .venv/bin/activate
PowerShell bloqueou o script? Erro comum: "a execução de scripts foi desabilitada neste sistema". Resolva com Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser, confirme com S e repita o passo 2. Alternativa: use o terminal cmd do VSCode (seta ao lado do botão + no painel de terminal).
3
Instalar as dependências
Com o ambiente ativado, instale pandas, scikit-learn, streamlit e demais bibliotecas listadas no requirements.txt (leva de 1 a 3 minutos):
(.venv) > pip install -r requirements.txt
4
(Opcional) Retreinar o pipeline
Se o pacote veio com as pastas modelos/ e data/ já preenchidas (arquivo modelo_knn.joblib presente), pule este passo. Caso contrário, gere a base e treine o modelo — o segundo comando leva alguns minutos, pois busca o melhor k entre 28 configurações com validação cruzada 5-fold:
(.venv) > python src/etl_preparacao.py (.venv) > python src/treino_knn.py
5
Iniciar a interface Streamlit
Suba o servidor local do aplicativo:
(.venv) > streamlit run app/app_streamlit.py
6
Usar o sistema
O navegador abre automaticamente em http://localhost:8501 (se não abrir, copie o endereço exibido no terminal). Na aba Simulador de Matrícula, preencha o perfil do candidato e clique em Prever desempenho para ver as notas previstas, os vizinhos consultados e o parecer com nível de risco. Para encerrar, volte ao terminal e pressione Ctrl + C.
Seção 4
Interface 2 — Dashboard Next.js
O dashboard web é a versão mais visual do SAD: cinco módulos com gráficos interativos, simulador com botões de preset para demonstração ao vivo (perfis de alto risco e favorável) e o motor K-NN executando no próprio navegador. Ele não exige Python — apenas Node.js. Abra a pasta dashboard_encceja_nextjs no VSCode e use o terminal integrado.
1
Instalar as dependências
Na primeira execução, o npm baixa Next.js, React, Recharts e as demais bibliotecas (de 1 a 2 minutos com internet):
> npm install
2
Iniciar o servidor de desenvolvimento
O modo de desenvolvimento compila sob demanda e recarrega a página a cada alteração no código:
> npm run dev
3
Explorar os cinco módulos
Acesse http://localhost:3000. Na aba Simulador K-NN, experimente os dois presets de demonstração — alto risco e favorável — para ver a comparação lado a lado das previsões, dos vizinhos e dos pareceres, recurso ideal para a gravação do vídeo de demonstração. Para produção otimizada, use npm run build seguido de npm start.
Seção 5
Rodando as duas ao mesmo tempo
As interfaces são independentes e ocupam portas diferentes (8501 e 3000), portanto podem rodar simultaneamente sem conflito — útil para comparar resultados ou demonstrar as duas versões na gravação do vídeo. No VSCode, abra um segundo terminal clicando no botão + no canto superior direito do painel de terminal: mantenha o primeiro com o ambiente virtual ativado servindo o Streamlit e use o segundo, sem ambiente virtual, para o dashboard Next.js. Cada terminal exibe o endereço local da sua interface, e ambos podem ser interrompidos de forma independente com Ctrl + C.
