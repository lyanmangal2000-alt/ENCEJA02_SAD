Seção 1
O que você vai rodar
O projeto entrega um Sistema de Apoio à Decisão (SAD) que prevê o desempenho de novos candidatos do ENCCEJA com o algoritmo K-Nearest Neighbors e converte a previsão em recomendações gerenciais para cursinhos preparatórios. Ele é composto por duas interfaces independentes que compartilham a mesma base de dados e a mesma lógica de modelagem. Não é necessário rodar as duas para avaliar o trabalho: cada uma cobre o ciclo completo de previsão e recomendação.
● Interface 1 — App Streamlit (Python)
Carrega o modelo K-NN treinado pelo pipeline (modelo_knn.joblib) e oferece três abas: Simulador de Matrícula, Base Histórica e Modelo & Métricas. Roda em http://localhost:8501.
● Interface 2 — Dashboard Next.js (Web)
Replica o K-NN inteiramente no navegador em TypeScript, com cinco módulos: Visão Geral, Simulador K-NN (com presets de demonstração), Recomendação, Análise Exploratória e Modelo & Métricas. Roda em http://localhost:3000.
O fluxo de dados é simples de entender: o pipeline Python lê os microdados (sintéticos ou oficiais do INEP), aplica o ETL, normaliza as variáveis com Z-score, treina o K-NN e serializa o modelo; o Streamlit consome esse modelo treinado; já o dashboard Next.js recebe uma amostra exportada da base com os parâmetros de padronização e executa a mesma aritmética de vizinhos no cliente. Por isso, o Streamlit depende da etapa de treinamento, enquanto o dashboard web funciona imediatamente após o npm install.

Preparar o ambiente
Antes de abrir o projeto, instale as ferramentas abaixo e confirme cada instalação pelo terminal (no Windows, use o PowerShell; no macOS/Linux, o terminal padrão). Se algum comando não for reconhecido, o respectivo instalador normalmente oferece a opção de adicionar a ferramenta ao PATH — marque essa opção durante a instalação para evitar problemas mais adiante.
