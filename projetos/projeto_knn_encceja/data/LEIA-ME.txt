Este diretório (`data/`) armazena os dados de entrada do pipeline.

## Como usar com os MICRODADOS OFICIAIS do INEP (recomendado)

1. Baixe o pacote "Microdados ENCCEJA 2024" em:
   https://www.gov.br/inep/pt-br/acesso-a-informacao/dados-abertos/microdados/encceja

2. Extraia e copie para ESTA pasta o arquivo de candidatos regulares:

       MICRODADOS_ENCCEJA_2024_REG_NAC.csv

3. Rode o pipeline normalmente (ver README na raiz do projeto). O script
   `src/config.py` detecta automaticamente o arquivo oficial e o prioriza.

4. ⚠️ IMPORTANTE: confira em `src/config.py` as constantes
   QUESTAO_TRABALHO / QUESTAO_RENDA / QUESTAO_ESCOLARIDADE e os mapeamentos
   MAP_TRABALHO / MAP_RENDA / MAP_ESCOLARIDADE contra o "Dicionário de
   variáveis" oficial do INEP que acompanha o pacote. A numeração Q01–Q75
   pode mudar entre edições do exame.

## Sem os microdados oficiais?

O arquivo `MICRODADOS_ENCCEJA_2024_REG_NAC_SINTETICO.csv` é gerado
automaticamente por `src/gerar_dados_sinteticos.py` (ou sob demanda pelo
pipeline) e permite testar TODO o sistema sem download. Ele segue o mesmo
schema e formato técnico do arquivo oficial (latin-1, separador ";").
